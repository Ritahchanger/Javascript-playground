## Getting Started

```bash
git clone https://github.com/Ritahchanger/Javascript-playground.git
cd Javascript-playground

# Plain JS files
node path/to/file.js

# Projects with their own package.json
cd category/project-name
npm install
npm start   # or: npm run dev
```

## Categories

- **[algorithms-dsa](./algorithms-dsa/)** — LeetCode, Codility, Amazon interview questions, core DSA implementations
- **[js-fundamentals](./js-fundamentals/)** — closures, prototypes, hoisting, error handling, OOP
- **[react-frontend](./react-frontend/)** — hooks, state management (Context, Redux, Zustand), animations, forms
- **[backend-node](./backend-node/)** — Node.js core, Express APIs, Prisma ORM, caching, a web-meeting server
- **[auth-security](./auth-security/)** — OAuth, GitHub auth, social login, role-based access control
- **[projects](./projects/)** — small full apps (todo apps, simple games)
- **[files-media](./files-media/)** — file system operations, camera/audio/video handling
- **[typescript](./typescript/)** — interfaces and type examples
